## Built-in Beam Transform Rules & Syntax Reference
- **GLOBAL MANDATORY RULE**: Check the `beam_transform` attribute on each node in the input YAML below.
- **NO CUSTOM `DoFn` / `ParDo` CLASSES**: For any node specifying a `beam_transform` attribute, you **MUST** use the native Apache Beam built-in `PTransform` from the SDK syntax table below. Writing custom `DoFn` or `ParDo` classes is **STRICTLY FORBIDDEN** unless explicit custom logic is requested in a node's `system_instructions`.
- **SDK SYNTAX OVERRIDES**:
  - **Python `WithTimestamps`**: Use `beam.Map(lambda x: beam.window.TimestampedValue(x, time.time()))` (with `import time`). Do NOT use `beam.WithTimestamps()`.

### Python SDK Syntax & Behavioral Reference:

#### 1. Sources & Sinks (I/O Connectors)
- **`PubSubIO`**:
  - Source: `beam.io.ReadFromPubSub(subscription=..., topic=...)`
  - Sink: `beam.io.WriteToPubSub(topic=...)`
- **`BigQueryIO`**:
  - Source: `beam.io.ReadFromBigQuery(query=..., table=..., use_standard_sql=True)`
  - Sink: `beam.io.WriteToBigQuery(table=..., create_disposition=..., write_disposition=...)`
- **`TextIO`**:
  - Source: `beam.io.ReadFromText(file_pattern=..., skip_header_lines=..., compression_type=..., delimiter=...)`
  - Sink: `beam.io.WriteToText(file_path_prefix=..., file_name_suffix=..., num_shards=..., compression_type=..., header=..., footer=...)`
- **`FileIO`**:
  - Match Source (`FileIO.match`): `beam.io.fileio.MatchFiles(file_pattern)` / `beam.io.fileio.MatchAll()`
  - Read Matches Step (`FileIO.readMatches`): `beam.io.fileio.ReadMatches(compression_type=...)` (produces `ReadableFile` elements)
  - Sink (`FileIO.write`): `beam.io.fileio.WriteToFiles(path=..., prefix=..., suffix=..., num_shards=..., ...)`
- **`Create`**:
  - Source: `beam.Create([...])`

#### 2. Element-Wise Transforms
- **`WithTimestamps`** (Add Timestamp):
  - Syntax: `beam.Map(lambda x: beam.window.TimestampedValue(x, time.time()))` (import `time`)
  - Default Instruction: Attach current system time (`time.time()`) to each element/message unless custom `system_instructions` are provided.
- **`Filter`**:
  - Syntax: `beam.Filter(lambda x: ...)`
  - Default Instruction: Create a custom function with a todo comment and return true unless custom `system_instructions` are provided.
- **`FlatMap`**:
  - Syntax: `beam.FlatMap(lambda x: x.split(','))` or `beam.FlatMap(lambda x: re.findall(r'[A-Za-z]+', x))`
- **`Keys`**:
  - Syntax: `beam.Keys()`
- **`KVMapper`**:
  - Syntax: `beam.Map(lambda x: (x.get('id'), x))`
  - Default Instruction: Map incoming dictionary/object into a `(key, value)` tuple using the configured key property (defaults to `'id'`).
- **`KvSwap`**:
  - Syntax: `beam.KvSwap()`
  - Default Instruction: Swap key and value of incoming `(K, V)` pairs into `(V, K)`.
- **`Map`**:
  - Syntax: `beam.Map(lambda x: ...)`
- **`ToString`**:
  - Syntax: `beam.ToString.Element()` / `beam.ToString.KVs()`
- **`Values`**:
  - Syntax: `beam.Values()`

#### 3. Aggregations & Combining
- **`ApproximateQuantiles`**:
  - Syntax: `beam.approximatequantiles.ApproximateQuantiles.Globally(...)` / `.PerKey(...)`
- **`ApproximateUnique`**:
  - Syntax: `beam.ApproximateUnique.Globally(...)` / `.PerKey(...)`
- **`BatchElements`**:
  - Syntax: `beam.BatchElements(min_batch_size=..., max_batch_size=...)`
- **`CoGroupByKey`**:
  - Syntax: `beam.CoGroupByKey()`
- **`Combine`**:
  - Syntax: `beam.CombineGlobally(...)` / `beam.CombinePerKey(...)`
- **`CombineWithContext`**:
  - Syntax: `beam.CombineGlobally(...).with_defaults()`
- **`Count`**:
  - Syntax: `beam.combiners.Count.PerElement()` / `beam.combiners.Count.PerKey()` / `beam.combiners.Count.Globally()`
- **`Distinct`**:
  - Syntax: `beam.Distinct()`
- **`GroupByKey`**:
  - Syntax: `beam.GroupByKey()`
- **`GroupIntoBatches`**:
  - Syntax: `beam.GroupIntoBatches(batch_size=...)`
- **`Latest`**:
  - Syntax: `beam.combiners.Latest.PerKey()` / `beam.combiners.Latest.Globally()`
- **`Max`**:
  - Syntax: `beam.combiners.Top.Of(...)` or `beam.Max.PerKey()` / `beam.Max.Globally()`
- **`Mean`**:
  - Syntax: `beam.combiners.Mean.PerKey()` / `beam.combiners.Mean.Globally()`
- **`Min`**:
  - Syntax: `beam.Min.PerKey()` / `beam.Min.Globally()`
- **`Sample`**:
  - Syntax: `beam.combiners.Sample.FixedSizeGlobally(...)` / `.FixedSizePerKey(...)`
- **`Sum`**:
  - Syntax: `beam.combiners.Sum.PerKey()` / `beam.combiners.Sum.Globally()`
- **`Top`**:
  - Syntax: `beam.combiners.Top.Of(...)` / `beam.combiners.Top.PerKey(...)`

#### 4. Windowing, Parsing & Utility Transforms
- **`WindowInto`**:
  - Syntax: `beam.WindowInto(window.FixedWindows(...))` / `SlidingWindows` / `Sessions`
- **`ParseMessage`**:
  - Parse Pub/Sub bytes string into JSON / String / Base64.
- **`LogMessage`**:
  - Syntax: `beam.Map(lambda x: logging.info(f"Log: {x}"))`

#### 5. Other Transforms
- **`Flatten`**:
  - Syntax: `(pcoll1, pcoll2) | beam.Flatten()` or `[pcoll1, pcoll2] | beam.Flatten()`
  - Rules: Merges multiple `PCollection` objects containing elements of the same data type into a single logical `PCollection`. Pass a tuple or list of `PCollection` objects into `beam.Flatten()`.
- **`Reshuffle`** / **`ReShuffle`**:
  - Syntax: `beam.Reshuffle()` or `beam.Reshuffle(num_buckets=...)`
  - Rules: Redistributes elements across workers by assigning temporary random keys to break runner stage fusion and balance parallel workload.
