## Built-in Beam Transform Rules & Syntax Reference
- **GLOBAL MANDATORY RULE**: Check the `beam_transform` attribute on each node in the input YAML below.
- **NO CUSTOM `DoFn` / `ParDo` CLASSES**: For any node specifying a `beam_transform` attribute, you **MUST** use the native Apache Beam built-in `PTransform` from the SDK syntax table below. Writing custom `DoFn` or `ParDo` classes is **STRICTLY FORBIDDEN** unless explicit custom logic is requested in a node's `systemInstructions`.
- **SDK SYNTAX OVERRIDES**:
  - **Python `WithTimestamps`**: Use `beam.Map(lambda x: beam.window.TimestampedValue(x, time.time()))` (with `import time`). Do NOT use `beam.WithTimestamps()`.

### SDK Syntax & Behavioral Reference:

#### 1. Sources & Sinks (I/O Connectors)
- **`PubSubIO`**:
  - Python Source: `beam.io.ReadFromPubSub(subscription=..., topic=...)`
  - Python Sink: `beam.io.WriteToPubSub(topic=...)`
  - Java Source: `PubsubIO.readStrings().fromSubscription(...)` / `fromTopic(...)`
  - Java Sink: `PubsubIO.writeStrings().to(...)`
- **`BigQueryIO`**:
  - Python Source: `beam.io.ReadFromBigQuery(query=..., table=..., use_standard_sql=True)`
  - Python Sink: `beam.io.WriteToBigQuery(table=..., create_disposition=..., write_disposition=...)`
  - Java Source: `BigQueryIO.readTableRows().from(...)` / `.fromQuery(...)`
  - Java Sink: `BigQueryIO.writeTableRows().to(...)`
- **`Create`**:
  - Python Source: `beam.Create([...])`
  - Java Source: `Create.of([...])`

#### 2. Element-Wise Transforms
- **`WithTimestamps`** (Add Timestamp):
  - Python: `beam.Map(lambda x: beam.window.TimestampedValue(x, time.time()))` (import `time`)
  - Java: `WithTimestamps.of((element) -> org.joda.time.Instant.now())` or `WithTimestamps.of(...)`
  - Default Instruction: Attach current system time (`time.time()` in Python, `Instant.now()` in Java) to each element/message unless custom `systemInstructions` are provided.
- **`Filter`**:
  - Python: `beam.Filter(lambda x: ...)`
  - Java: `Filter.by(...)`
- **`FlatMap`**:
  - Python: `beam.FlatMap(lambda x: ...)`
  - Java: `FlatMapElements.into(...).via(...)`
- **`Keys`**:
  - Python: `beam.Keys()`
  - Java: `Keys.create()`
- **`KVMapper`**:
  - Python: `beam.Map(lambda x: (x.get('id'), x))`
  - Java: `WithKeys.of(...)`
  - Default Instruction: Map incoming dictionary/object into a `(key, value)` tuple using the configured key property (defaults to `'id'`).
- **`KvSwap`**:
  - Python: `beam.KvSwap()`
  - Java: `KvSwap.of()`
  - Default Instruction: Swap key and value of incoming `(K, V)` pairs into `(V, K)`.
- **`Map`**:
  - Python: `beam.Map(lambda x: ...)`
  - Java: `MapElements.into(...).via(...)`
- **`ToString`**:
  - Python: `beam.ToString.Element()` / `beam.ToString.KVs()`
  - Java: `ToString.elements()` / `ToString.kvs()`
- **`Values`**:
  - Python: `beam.Values()`
  - Java: `Values.create()`

- **`ApproximateQuantiles`**:

## Language SDK Best Practices & Gotchas

### Java Projects
- **Strict XML Syntax (`pom.xml`)**: Ensure strictly valid XML without stray characters.
- **Jackson Dependency Alignment**: Explicitly declare `com.fasterxml.jackson.core:jackson-core`, `jackson-databind`, and `jackson-annotations` version `2.15.3` (or higher) in `pom.xml` to avoid runtime `NoClassDefFoundError: StreamReadConstraints`.
- **Testing Dependencies**: Include `junit:junit:4.13.2`, `org.hamcrest:hamcrest:2.2`, `org.hamcrest:hamcrest-library:2.2`, and `org.junit.vintage:junit-vintage-engine:${junit.version}` under `<scope>test</scope>`.
- **Maven Shade Plugin Output**: Set `<outputFile>${project.build.directory}/main.jar</outputFile>` in `maven-shade-plugin` so `target/main.jar` is predictable for Docker copying.
- **Coders**: Avoid returning `PCollection<Map<String, Object>>` without an explicit coder. Use `.setCoder(...)` or Beam `Row` schema (`PCollection<Row>`).
- **BigQueryIO Return Type**: `BigQueryIO.readTableRows()` returns `BigQueryIO.TypedRead<TableRow>`, NOT `TypedRead<String>`.
- **String Coder API**: Use `StringUtf8Coder.of()` (`org.apache.beam.sdk.coders.StringUtf8Coder`), NOT `StringCoder`.
- **Side Output Emission**: Use `c.output(tag, value)` in `DoFn.ProcessContext`.

### Python Projects
- **Python 3.12+ Compatibility**: In `requirements.txt`, specify `apache-beam[gcp]>=2.74.0` (do NOT pin old packages requiring deprecated `pkg_resources`). Do NOT include `pyspark`.
- **Package Marker**: Always generate `src/__init__.py`.
- **Unit Test Imports**: In unit tests, import the pipeline module using `from src.<pipeline_name> import ...` or `from <pipeline_name> import ...`.
