## Built-in Beam Transform Rules & Syntax Reference
- **GLOBAL MANDATORY RULE**: Check the `beam_transform` attribute on each node in the input YAML below.
- **NO CUSTOM `DoFn` / `ParDo` CLASSES**: For any node specifying a `beam_transform` attribute, you **MUST** use the native Apache Beam built-in `PTransform` from the SDK syntax table below. Writing custom `DoFn` or `ParDo` classes is **STRICTLY FORBIDDEN** unless explicit custom logic is requested in a node's `system_instructions`.

### Java SDK Syntax & Behavioral Reference:

#### 1. Sources & Sinks (I/O Connectors)
- **`PubSubIO`**:
  - Source: `PubsubIO.readStrings().fromSubscription(...)` / `fromTopic(...)`
  - Sink: `PubsubIO.writeStrings().to(...)`
- **`BigQueryIO`**:
  - Source: `BigQueryIO.readTableRows().from(...)` / `.fromQuery(...)`
  - Sink: `BigQueryIO.writeTableRows().to(...)`
- **`Create`**:
  - Source: `Create.of([...])`

#### 2. Element-Wise Transforms
- **`WithTimestamps`** (Add Timestamp):
  - Syntax: `WithTimestamps.of((element) -> org.joda.time.Instant.now())` or `WithTimestamps.of(...)`
  - Default Instruction: Attach current system time (`Instant.now()`) to each element/message unless custom `system_instructions` are provided.
- **`Filter`**:
  - Syntax: `Filter.by(...)`
  - Default Instruction: Create a custom function with a todo comment and return true unless custom `system_instructions` are provided.
- **`FlatMap`**:
  - Syntax: `FlatMapElements.into(TypeDescriptors.strings()).via((String x) -> Arrays.asList(x.split(",")))`
- **`Keys`**:
  - Syntax: `Keys.create()`
- **`KVMapper`**:
  - Syntax: `WithKeys.of(...)`
  - Default Instruction: Map incoming dictionary/object into a `(key, value)` tuple using the configured key property (defaults to `'id'`).
- **`KvSwap`**:
  - Syntax: `KvSwap.of()`
  - Default Instruction: Swap key and value of incoming `(K, V)` pairs into `(V, K)`.
- **`Map`**:
  - Syntax: `MapElements.into(...).via(...)`
- **`ToString`**:
  - Syntax: `ToString.elements()` / `ToString.kvs()`
- **`Values`**:
  - Syntax: `Values.create()`

#### 3. Aggregations & Combining
- **`ApproximateQuantiles`**:
  - Syntax: `ApproximateQuantiles.globally(...)` / `.perKey(...)`
- **`ApproximateUnique`**:
  - Syntax: `ApproximateUnique.globally(...)` / `.perKey(...)`
- **`BatchElements`**:
  - Syntax: `BatchElements.of(...)`
- **`CoGroupByKey`**:
  - Syntax: `CoGroupByKey.create()`
- **`Combine`**:
  - Syntax: `Combine.globally(...)` / `Combine.perKey(...)`
- **`CombineWithContext`**:
  - Syntax: `Combine.globally(...)`
- **`Count`**:
  - Syntax: `Count.perElement()` / `Count.perKey()` / `Count.globally()`
- **`Distinct`**:
  - Syntax: `Distinct.create()`
- **`GroupByKey`**:
  - Syntax: `GroupByKey.create()`
- **`GroupIntoBatches`**:
  - Syntax: `GroupIntoBatches.ofSize(...)`
- **`Latest`**:
  - Syntax: `Latest.perKey()` / `Latest.globally()`
- **`Max`**:
  - Syntax: `Max.integersPerKey()` / `Max.doublesPerKey()` / `Max.globally(...)`
- **`Mean`**:
  - Syntax: `Mean.perKey()` / `Mean.globally()`
- **`Min`**:
  - Syntax: `Min.integersPerKey()` / `Min.doublesPerKey()` / `Min.globally(...)`
- **`Sample`**:
  - Syntax: `Sample.fixedSizeGlobally(...)` / `Sample.fixedSizePerKey(...)`
- **`Sum`**:
  - Syntax: `Sum.integersPerKey()` / `Sum.doublesPerKey()` / `Sum.globally(...)`
- **`Top`**:
  - Syntax: `Top.largest(...)` / `Top.smallest(...)`

#### 4. Windowing, Parsing & Utility Transforms
- **`WindowInto`**:
  - Syntax: `Window.into(FixedWindows.of(...))` / `SlidingWindows` / `Sessions`
- **`ParseMessage`**:
  - Parse Pub/Sub bytes string into JSON / String / Base64.
- **`LogMessage`**:
  - Syntax: `ParDo.of(new LogDoFn())`

#### 5. Other Transforms
- **`Flatten`**:
  - Syntax: `PCollectionList.of(pcoll1).and(pcoll2).apply(Flatten.pCollections())`
  - Rules: Merges multiple `PCollection` objects containing elements of the same data type into a single logical `PCollection`. Input `PCollection` objects are combined into a `PCollectionList` before applying `Flatten.pCollections()`.
- **`Reshuffle`** / **`ReShuffle`**:
  - Syntax: `Reshuffle.of()`
  - Rules: Redistributes elements across workers by assigning temporary random keys to break runner stage fusion and balance parallel workload.

## Language SDK Best Practices & Gotchas

### Java Projects
- **Strict XML Syntax (`pom.xml`)**: Ensure strictly valid XML without stray characters.
- **Jackson Dependency Alignment**: Explicitly declare `com.fasterxml.jackson.core:jackson-core`, `jackson-databind`, and `jackson-annotations` version `2.15.3` (or higher) in `pom.xml` to avoid runtime `NoClassDefFoundError: StreamReadConstraints`.
- **Testing Dependencies**: Include `junit:junit:4.13.2`, `org.hamcrest:hamcrest:2.2`, `org.hamcrest:hamcrest-library:2.2`, and `org.junit.vintage:junit-vintage-engine:${junit.version}` under `<scope>test</scope>`.
- **Maven Shade Plugin Output**: Set `<outputFile>${project.build.directory}/main.jar</outputFile>` in `maven-shade-plugin` so `target/main.jar` is predictable for Docker copying.
- **Coders**: Avoid returning `PCollection<Map<String, Object>>` without an explicit coder. Use `.setCoder(...)` or Beam `Row` schema (`PCollection<Row>`).
- **BigQueryIO Return Type**: `BigQueryIO.readTableRows()` returns `BigQueryIO.TypedRead<TableRow>`, NOT `TypedRead<String>`.
- **String Coder API**: Use `StringUtf8Coder.of()` (`org.apache.beam.sdk.coders.StringUtf8Coder`), NOT `StringCoder`.
- **Side Output Emission**: Use `c.output(tag, value)` in `DoFn.ProcessContext`.
